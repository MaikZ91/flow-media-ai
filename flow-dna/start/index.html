Schritt 1 · kurz verstehen

Chat ist nicht gleich Agent.

Claude und ChatGPT gibt es in drei Formen:

WebIm Browser auf claude.ai oder chatgpt.com. Gut zum Chatten – aber sie sieht nichts auf deinem Computer.
Desktop-App Für den WorkshopEin Programm auf deinem Computer. Darin steckt der Agent, der direkt mit deinen Dateien arbeitet.
Terminal FortgeschrittenDasselbe als Befehl im Terminal. Für alle, die schon mit der Kommandozeile arbeiten.
Chat
  • Claude-Chat, ChatGPT-Chat
  • beantwortet Fragen
  • du kopierst die Ergebnisse selbst raus
Agent
  • Claude Code, Codex
  • bekommt eine Aufgabe und erledigt sie
  • legt Dateien an, baut Websites und Apps
Warum die Desktop-App?Sie arbeitet auf deinem Computer, in einem Ordner, den du auswählst. Dort legt sie Dateien an und baut deine Website oder App. Im Browser-Chat geht das nicht.

Du brauchst nur eine der beiden Apps. Wenn du schon ein bezahltes Claude-Abo hast, nimm Claude Code. Wenn du ChatGPT bezahlst, nimm Codex.

Schritt 3 · zwei Einstellungen

Modell & Berechtigung

Welches Modell?

Das Modell ist das „Gehirn“, mit dem der Agent arbeitet. Für Claude Code empfehle ich:

Opus 5.5 · MediumStandard für fast alles: Websites, Apps, Design, Texte. Damit fährst du im Workshop richtig.
Haiku 5.5Für schnelle, kleine Aufgaben. Antwortet am schnellsten.
Fable 5.2Für sehr große, schwierige Projekte. Braucht länger und mehr Kontingent.

Stand: November 2026. Die Modelle wechseln alle paar Monate – diese Seite wird aktualisiert. In Codex wählst du Modell und „Denktiefe“ ebenfalls im Eingabebereich; nimm dort das empfohlene Standardmodell.

Welche Berechtigung?

Der Modus legt fest, wie oft der Agent dich fragt, bevor er etwas tut. In Claude Code stellst du ihn in der Leiste unter dem Eingabefeld ein:

AutoEmpfehlung. Der Agent arbeitet flüssig und fragt nur bei riskanten Schritten. Gibt es „Auto“ bei dir nicht, nimm Accept edits.
ManualFragt bei jedem Schritt. Sicher, aber im Workshop zäh.
PlanPlant erst, ändert noch nichts. Gut zum Besprechen.
Bypass permissionsNicht verwenden. Fragt gar nicht mehr nach.

In Codex lässt du die voreingestellte Berechtigung einfach so, wie sie ist.

Optional

Terminal Fortgeschritten

Nur für alle, die schon mit dem Terminal arbeiten. Für den Workshop reicht die Desktop-App.

Claude Code im Terminal

Mac / Linux:

curl -fsSL https://claude.ai/install.sh | bash

Windows (PowerShell):

irm https://claude.ai/install.ps1 | iex

Danach im Projektordner claude eingeben und beim ersten Start anmelden. Prüfen mit claude --version.

Codex im Terminal

Mac / Linux:

curl -fsSL https://chatgpt.com/codex/install.sh | sh

Windows (neues PowerShell-Fenster):

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

Danach im Projektordner codex eingeben und „Sign in with ChatGPT“ wählen. Modell wechseln mit /model, Berechtigungen mit /permissions.
