# Flow DNA – Skill installieren

Jeder Skill ist ein Ordner mit einer `SKILL.md` (Name, Beschreibung, Anleitung für die KI) und – je nach Skill – Vorlagen, Beispielen oder Skripten.

## Claude Code
1. Skill-Ordner herunterladen (z. B. `post-analyzer/`).
2. Ablegen unter `.claude/skills/` in deinem Projekt **oder** unter `~/.claude/skills/` (dann gilt er überall).
3. Claude Code neu starten. Der Skill wird automatisch genutzt, wenn deine Anfrage zur Beschreibung passt – oder du rufst ihn direkt mit `/<name>` auf.

## Claude-App (claude.ai)
1. Skill-Ordner als ZIP packen.
2. Einstellungen → Fähigkeiten → Skills → **Skill hochladen** → ZIP wählen → aktivieren.

## Codex
Ordner in den Skill-Ordner deines Codex-Projekts legen (siehe Codex-Doku zu Skills) – die `SKILL.md` ist reines Markdown und funktioniert dort genauso.

## Tipp
Viele Flow-DNA-Skills arbeiten besser, wenn deine Marke als Skill vorliegt. Starte deshalb mit **Flow DNA Personal Brand** – danach schreiben alle anderen Skills in deiner Stimme.

Fragen, Fehler, Wünsche: in der Flow Business Community oder direkt an Maik (Flow Media AI).
