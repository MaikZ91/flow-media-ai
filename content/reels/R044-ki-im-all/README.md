## Neu rendern
1. Texturen nach `tex/` laden (liegen nicht im Repo): von `https://www.solarsystemscope.com/textures/download/` die Dateien `8k_earth_daymap.jpg`, `8k_earth_nightmap.jpg`, `8k_earth_clouds.jpg`, `8k_earth_specular_map.tif` (als `earth_spec.jpg` in Graustufen speichern), `8k_moon.jpg`, `8k_mars.jpg`, `8k_stars_milky_way.jpg`.
2. `python3 -m http.server 8774` in diesem Ordner, dann `node render.js` (ca. 17 Minuten mit drei parallelen Bereichen, z. B. `node render.js 0 300`).
3. `bash build.sh` → `R044.mp4`.
Standbilder zur Kontrolle: `node shot.js 1.5 9.0 19.9` (mit `NOTEXT=1` ohne Text).
