## Neu bauen
Die 3D-Technik (Erde, Atmosphäre, Sterne, Satellit, Rakete) kommt aus `../R044-ki-im-all/space.html`. `python3 gen.py` setzt daraus und aus `models.js`, `scenes.js`, `dom.html`, `extra.css` die Datei `time.html` zusammen. `tex` zeigt auf `../R044-ki-im-all/tex` (Texturen dort laden, siehe R044-README).
Dann `python3 -m http.server 8775`, `node render.js 0 305` (drei Bereiche parallel, ca. 15 Minuten), `bash build.sh` → `R045.mp4`. Standbilder: `node shot.js 1.0 14.6 26.0`.
