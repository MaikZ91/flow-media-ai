## Was gemessen wird und ab wann gehandelt wird

| Kennzahl | Quelle | Richtwert / Eingreifen |
|---|---|---|
| **Hook-Rate** = 3-s-Abspielungen ÷ Impressionen | Meta | unter 25 % nach ≥ 1.000 Impressionen → Hook (erste 1,5 s) neu bauen |
| **Hold** = Anteil bis 50 % / bis Ende (video_p50 / p100 ÷ Abspielungen) | Meta | Ende unter 15 % → Reel kürzen (Szene 2 straffen), Endkarte früher |
| **CTR (Link)** | Meta | unter 0,8 % nach ≥ 1.500 Impressionen → Anfang/CTA ändern |
| **Kosten pro Seitenaufruf** | Meta | über 1,00 $ → Zielgruppe/Creative prüfen |
| **Leads (Meta)** & **Kosten pro Lead** | Meta (Lead-Event Datensatz Flow, CAPI) | Lernphase: Meta braucht Leads; nach 7 Tagen ohne Lead → zurück auf Landingpage-Aufrufe oder neues Creative |
| **Beitritte (PostHog)** = community_join_click, eindeutige Sitzungen, ohne Meta-Prüf-Rechenzentren | PostHog | Beitritte pro 100 echte Besucher; unter 3 → Seite prüfen |
| **Seite**: echte Besucher, Anteil `layout=reel`, Klicks je Profil (Gründer:in / Selbstständig / Angestellt) | PostHog | zeigt, wer kommt |
| **Follower** (Stand + Δ zum Vortag) | Instagram API | Nebeneffekt, kein Ziel |
| **Frequenz** | Meta | über 2,5 in 7 Tagen → Creative-Ermüdung, neues Reel nachschieben |

Regel: Eine Änderung pro Runde, frühestens nach 3 Tagen Daten (Lernphase), und nur mit Zahl begründet.
