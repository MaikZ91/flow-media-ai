Am Ende kannst du direkt über das Terminal mit deinem KI-Agenten arbeiten.

  1. Installiere eine CLIWähle Codex CLI oder Claude Code und folge der Anleitung für dein Betriebssystem. Öffne danach ein Terminal.
  2. Wechsle in deinen ProjektordnerÖffne den Ordner flow-workshop aus Basic oder leg ihn neu an. Wechsle im Terminal mit cd "PFAD/ZU/flow-workshop" dorthin und ersetze den Beispielpfad durch deinen eigenen. Lege dort eine briefing.md mit Angebot, Zielgruppe und Ton an, falls sie noch fehlt.
  3. Starte den AgentenFühre im Projektordner codex oder claude aus. Melde dich an, falls die CLI dich dazu auffordert. Gib den Auftrag unten in die gestartete Sitzung ein und prüfe die erzeugte Datei.
