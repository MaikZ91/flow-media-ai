Background & Theorie

So arbeitet dein Agent im Workspace

Ein Workspace ist dein Projektordner. Du gibst dem Agenten ein Briefing und Zugriff auf den Ordner. Der Agent legt die Datei dort ab. Im Browser prüfst du, ob das Ergebnis zu deiner Idee passt.

Claude Code oder Codex einrichten

Textanleitung in Flow DNA

Deine Aufgabe

Gestalte deine Projektkarte

Lass deinen Agenten eine kleine Website für eine echte oder fiktive Idee bauen. Sie zeigt den Projektnamen, für wen die Idee gedacht ist und was du als Nächstes vorhast.

Praktische Umsetzung

Baue die Karte in der Desktop-App

  1. App installierenWähle die Codex-App oder Claude Desktop. Melde dich an und öffne Codex oder den Bereich „Code“ in Claude.
  2. Projektordner öffnenErstelle einen leeren Ordner namens flow-workshop und wähle ihn in der App aus.
  3. Auftrag startenFülle den Prompt-Generator aus und füge den fertigen Prompt in der App ein.
Was macht der Prompt?

Deine Angaben sind das Briefing. Der Agent macht daraus den Inhalt und das Design deiner Projektkarte. Er speichert beides in einer HTML-Datei und nennt dir zum Schluss den Speicherort.

HTML legt fest, welche Inhalte auf der Karte stehen. CSS bestimmt Farben, Schrift und Layout. Das CSS steckt in derselben Datei, deshalb reicht eine einzige Datei zum Öffnen im Browser.

Prompt-Generator

Beschreibe dein Projekt. Deine Angaben erscheinen direkt im Prompt darunter.

Dein Ergebnis

Finde und prüfe deine Datei

  1. Öffne flow-workshop im Finder oder Datei-Explorer. Dort sollte projektkarte.html liegen.
  2. Öffne die Datei per Doppelklick im Browser. Stimmen Projektname, Zielgruppe und nächster Schritt mit deinem Briefing überein?

Falls die Datei fehlt, vergleiche den vom Agenten genannten Pfad mit deinem geöffneten Ordner. Mach einen Screenshot der Karte.

So teilst du dein Ergebnis · Zur Checkliste

Background & Theorie

Der Ordner bestimmt den Arbeitsbereich

Die CLI ist die Oberfläche für deinen Agenten im Terminal. Wenn du sie im Projektordner startest, kann der Agent dort Dateien lesen und anlegen, soweit du ihm Zugriff gibst.

Terminal-Anleitung in Flow DNA

Deine Aufgabe

Gestalte deine Projektkarte

Lass deinen Agenten eine kleine Website für eine echte oder fiktive Idee bauen. Sie zeigt den Projektnamen, für wen die Idee gedacht ist und was du als Nächstes vorhast.

Praktische Umsetzung

Baue die Karte im Terminal

  1. CLI installierenWähle Codex CLI oder Claude Code und folge der Anleitung für dein Betriebssystem.
  2. Projektordner öffnenLege flow-workshop an oder nutze deinen vorhandenen Ordner. Wechsle mit cd "PFAD/ZU/flow-workshop" hinein. Ersetze den Beispielpfad durch deinen eigenen.
  3. Agent startenStarte codex oder claude, melde dich bei Bedarf an und füge den fertigen Prompt aus dem Generator in die Agentensitzung ein.
Was macht der Prompt?

Deine Angaben sind das Briefing. Der Agent macht daraus den Inhalt und das Design deiner Projektkarte. Er speichert beides in einer HTML-Datei und nennt dir zum Schluss den Speicherort.

HTML legt fest, welche Inhalte auf der Karte stehen. CSS bestimmt Farben, Schrift und Layout. Das CSS steckt in derselben Datei, deshalb reicht eine einzige Datei zum Öffnen im Browser.

Prompt-Generator

Beschreibe dein Projekt. Deine Angaben erscheinen direkt im Prompt darunter.

Dein Ergebnis

Finde und prüfe deine Datei

  1. Öffne flow-workshop im Finder oder Datei-Explorer. Dort sollte projektkarte-terminal.html liegen. Im Terminal kannst du den Inhalt des aktuellen Ordners mit ls oder unter Windows mit dir anzeigen.
  2. Öffne die Datei per Doppelklick im Browser. Stimmen Projektname, Zielgruppe und nächster Schritt mit deinem Briefing überein?

Falls die Datei fehlt, vergleiche den vom Agenten genannten Pfad mit deinem geöffneten Ordner. Mach einen Screenshot der Karte und schreib beim Teilen dazu, dass du sie im Terminal gebaut hast.

So teilst du dein Ergebnis · Zur Checkliste
